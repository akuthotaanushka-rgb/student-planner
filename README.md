# Student Planner — To-Do List

A simple, responsive student task planner built with HTML, CSS, and vanilla JavaScript.

## Features

- Add tasks and delete tasks
- Mark tasks as completed
- Filter all, active, and completed tasks
- Clear completed tasks
- Automatically saves tasks in browser `localStorage`
- Responsive layout for desktop and mobile
- No frameworks or installation required

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Add your tasks and start planning.

## Files

- `index.html` — page structure
- `style.css` — design and responsive styling
- `script.js` — task interactions and local storage

## GitHub Pages

To publish it, open your repository's **Settings → Pages**, select the branch you want to deploy (usually `main`) and the root folder, then save. GitHub will provide a website URL after deployment is ready.
