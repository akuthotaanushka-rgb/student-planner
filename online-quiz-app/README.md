# QuickQuiz — Online Quiz App

A beginner-friendly, responsive quiz website made with HTML, CSS, and JavaScript.

## Features
- Five general-knowledge and web basics questions
- 30-second timer for each question
- Multiple-choice answers with visual feedback
- Automatic score and percentage calculation
- Answer review with explanations
- Restart option
- Responsive layout for desktop and mobile
- No frameworks or installation required

## Run locally
1. Download or clone this repository.
2. Open the `online-quiz-app` folder.
3. Open `index.html` in your web browser.

## Publish with GitHub Pages
1. Open the repository's **Settings** tab on GitHub.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then click **Save**.
5. Since this app is inside the `online-quiz-app` folder, open its `index.html` from the repository to verify the files. For a direct Pages URL, move these app files to the repository root or configure a dedicated Pages deployment for this folder.
